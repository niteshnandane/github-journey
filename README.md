# github-journey
                                               (1)  Introduction to git
Git एक Distributed Version Control System (DVCS) है। आसान शब्दों में कहें तो, यह सॉफ्टवेयर डेवलपर्स के लिए एक "टाइम मशीन" या "प्रोजेक्ट का इतिहास (History) रखने वाली डायरी" की तरह है।

जब आप कोई सॉफ्टवेयर या वेबसाइट बनाते हैं, तो कोड में बार-बार बदलाव करने पड़ते हैं। अगर कोई नया बदलाव करने से पुराना (सही) कोड खराब हो जाए, तो Git की मदद से आप चुटकियों में अपने प्रोजेक्ट को पहले वाली सही स्थिति (State) में वापस ला सकते हैं।

Git की मुख्य विशेषताएँ (Key Features of Git) Version Control (वर्जन कंट्रोल): यह आपके कोड के हर बदलाव को रिकॉर्ड करता है। आप देख सकते हैं कि किस फाइल में, कब और किसने बदलाव किया था।

Distributed (वितरित प्रणाली): इसमें हर डेवलपर के पास पूरे प्रोजेक्ट का पूरा इतिहास (History) उसकी अपनी लोकल मशीन पर होता है, जिससे इंटरनेट न होने पर भी काम किया जा सकता है।

Collaboration (सहयोग): कई डेवलपर्स एक ही प्रोजेक्ट पर एक साथ बिना एक-दूसरे के काम में बाधा डाले काम कर सकते हैं।

Branching & Merging (ब्रांचिंग और मर्जिंग): आप अपनी मुख्य फाइल को छेड़े बिना एक नई "Branch" (शाखा) बनाकर नए फीचर्स पर प्रयोग कर सकते हैं। काम पूरा होने पर उसे मुख्य कोड में जोड़ (Merge) सकते हैं।

Git और GitHub में क्या अंतर है? (Difference between Git and GitHub) लोग अक्सर Git और GitHub को एक ही समझ लेते हैं, लेकिन दोनों अलग हैं:

Git: यह एक टूल/सॉफ्टवेयर है जो आपके कंप्यूटर पर कोड के वर्जन को मैनेज करता है।

GitHub: यह एक क्लाउड-आधारित प्लेटफॉर्म (वेबसाइट) है, जहाँ आप अपने Git रिपॉजिटरी (Codebase) को ऑनलाइन स्टोर और शेयर करते हैं (जैसे- Microsoft, Google या अन्य डेवलपर्स के साथ)।

                                         (2)Process of installing Git
Windows में Git कैसे इनस्टॉल करें? स्टेप 1: Git डाउनलोड करें

अपने ब्राउज़र में ऑफिशियल वेबसाइट खोलें: git-scm.com

होमपेज पर दिए गए "Download for Windows" बटन पर क्लिक करें। डाउनलोड अपने आप शुरू हो जाएगा।

स्टेप 2: इंस्टॉलर रन करें

डाउनलोड होने के बाद, .exe फाइल पर डबल-क्लिक करके उसे ओपन करें।

अगर कोई सिक्योरिटी परमिशन मांगे, तो 'Yes' पर क्लिक करें।

स्टेप 3: सेटअप सेटिंग्स (Settings) इंस्टॉलेशन के दौरान कई स्क्रीन आएंगी। ज़्यादातर सेटिंग्स को डिफ़ॉल्ट (Default) ही रहने दें और बार-बार 'Next' पर क्लिक करते जाएं। खास बातें ध्यान रखें:

Choosing the default editor: आप इसे डिफ़ॉल्ट (जैसे Notepad++ या VS Code यदि इनस्टॉल हो) पर रहने दें।

Adjusting your PATH environment: सुनिश्चित करें कि "Git from the command line and also from 3rd-party software" वाला विकल्प चुना हुआ हो।

Choosing HTTPS transport backend: डिफ़ॉल्ट विकल्प (OpenSSL library) को चुनें।

Choosing the line ending conversions: "Checkout Windows-style, commit Unix-style line endings" को चुनें (यह विंडोज़ यूजर्स के लिए सबसे अच्छा है)।

स्टेप 4: इंस्टॉलेशन पूरा करें आखिर में 'Install' बटन पर क्लिक करें। इंस्टॉलेशन पूरा होने के बाद 'Finish' पर क्लिक कर दें।

                                           Github Introduction

                                           GitHub क्या है? (What is GitHub?)
GitHub एक क्लाउड-आधारित (Cloud-based) प्लेटफॉर्म है, जिसका उपयोग डेवलपर्स (Developers) अपने Git कोड को ऑनलाइन स्टोर, शेयर और मैनेज करने के लिए करते हैं।

इसे आसान भाषा में कहें तो यह डेवलपर्स के लिए फेसबुक या गूगल ड्राइव जैसा है, जहाँ वे अपना कोड अपलोड करते हैं ताकि पूरी दुनिया या उनकी टीम के सदस्य उसे देख सकें और उसमें सुधार कर सकें।

नोट: जैसा कि हमने पहले पढ़ा, Git एक सॉफ्टवेयर है जो आपके कंप्यूटर पर काम करता है, जबकि GitHub एक वेबसाइट/प्लेटफॉर्म है जो इंटरनेट पर आपके कोड को सुरक्षित रखती है।

GitHub की मुख्य विशेषताएँ (Key Features of GitHub) Cloud Storage (क्लाउड स्टोरेज): आपका कोड आपके कंप्यूटर के अलावा इंटरनेट पर भी सुरक्षित रहता है। अगर आपका कंप्यूटर खराब भी हो जाए, तो भी आपका कोड सुरक्षित रहता है।

Collaboration (सहयोग): दुनिया के किसी भी कोने से कई डेवलपर्स एक ही प्रोजेक्ट पर एक साथ मिलकर काम कर सकते हैं।

Open Source (ओपन सोर्स): आप अपने प्रोजेक्ट को 'Public' कर सकते हैं ताकि दुनिया भर के अन्य डेवलपर्स आपके कोड को देख सकें, उसमें कमियां ढूंढ सकें या सुधार (Contribute) कर सकें।

Issue Tracking (समस्याओं को ट्रैक करना): प्रोजेक्ट में अगर कोई बग (Bug) या एरर है, तो GitHub पर "Issues" के जरिए उसे ट्रैक किया जा सकता है।

GitHub Pages: आप GitHub की मदद से अपनी स्टैटिक वेबसाइट (Static Website) को बिल्कुल मुफ्त में इंटरनेट पर लाइव (Host) कर सकते हैं।

GitHub से जुड़े कुछ महत्वपूर्ण शब्द (Important Terms) Repository (Repo): यह एक फोल्डर की तरह होता है जिसमें आपके प्रोजेक्ट की सारी फाइलें और उनका पूरा इतिहास (History) सेव रहता है।

Commit: अपने कोड में किए गए बदलावों को स्थायी रूप से सहेजना (Save करना)।

Pull Request (PR): जब आप किसी दूसरे के प्रोजेक्ट में या अपनी किसी दूसरी ब्रांच में बदलाव करके उसे मुख्य कोड में जुड़वाना चाहते हैं, तो आप एक अनुरोध (Request) भेजते हैं जिसे Pull Request कहते हैं।

Fork: किसी दूसरे डेवलपर के पब्लिक प्रोजेक्ट की कॉपी को अपने GitHub अकाउंट में ले लेना ताकि आप उसपर अपने हिसाब से काम कर सकें।
